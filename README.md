# Vishesh Singh Portfolio

This is a personal portfolio website built as a static HTML page.

## Project files

- `Vishesh_Singh_portfolio.html` — main portfolio page

## Features

- Responsive one-page portfolio layout
- Personal branding and project presentation
- Clean HTML/CSS styling
- No backend or dependency installation required

## Tools and technologies used

- HTML5 for structure and content
- CSS3 for layout, styling, and responsive design
- JavaScript for interactions and UI enhancements
- Python's built-in HTTP server for local preview (optional)
- Modern web browser for viewing the portfolio
- VS Code (recommended editor for editing the project)

## Run locally

You can view the site in any browser by opening the HTML file directly:

```bash
start Vishesh_Singh_portfolio.html
```

Or serve it locally with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Notes

This project is intentionally lightweight and does not require any external packages. The `requirements.txt` file is included for compatibility with Python-based tooling, but there are no runtime dependencies for the portfolio itself.
